# استخراج اقلام به اکسل (Android / Kotlin)

دکمه‌ی شناور «▶ شروع استخراج» روی **همه‌ی برنامه‌ها** می‌ماند. شما خودتان لیست «حذف اقلام فروشگاهی» را اسکرول می‌کنید و برنامه متن کارت‌ها را از طریق Accessibility (بدون OCR) می‌خواند. با «⏹ توقف» فایل اکسل ساخته می‌شود.

## راه‌اندازی
1. با Android Studio یا GitHub Actions (`.github/workflows/main.yml`) APK بسازید و نصب کنید.
2. برنامه را باز کنید و دو اجازه را بدهید:
   - سرویس دسترسی‌پذیری (اندروید ۱۳+: App info ▸ ⋮ ▸ Allow restricted settings، اگر خاکستری بود)
   - نمایش روی سایر برنامه‌ها
3. برنامه فروشگاهی ▸ صفحه «حذف اقلام فروشگاهی» ▸ «▶ شروع استخراج» ▸ لیست را اسکرول کنید ▸ «⏹ توقف».

## رنگ دکمه
- سبز: در حال خواندن (عدد = تعداد خوانده‌شده / تعداد کل صفحه)
- نارنجی: اسکرول خیلی سریع بود و ممکن است کالاهایی رد شده باشند؛ کمی به عقب برگردید.
- خاکستری: از صفحه‌ی لیست خارج شده‌اید؛ خواندن مکث کرده است.
- وقتی تعداد کامل به «تعداد» بالای صفحه برسد، خودکار ذخیره می‌شود.

## خروجی
`Download/ItemExporter/items_تاریخ.xlsx` با ستون‌های: ردیف، نام کالا، بارکد، موجودی، درصد ضایعات ماهیانه، قیمت (ریال)، توضیحات (متن آبی، بدون ستاره، مناسب مرتب‌سازی)، توضیحات (متن اصلی). فیلتر روشن، شیت راست‌به‌چپ.

## عیب‌یابی
دکمه را **لمس طولانی** کنید تا ساختار صفحه در `Download/ItemExporter/dump_*.txt` ذخیره شود.
